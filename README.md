## 官网和仿站、第三方站怎么分

搜索结果里中文站排得很靠前，识别方法有三条，够用：

1. **看域名**。官方只有 racknerd.com 和 my.racknerd.com（客户区）、ctrl.racknerd.com（面板）、status.racknerd.com（网络状态）。以 .cc、.cn、.net 结尾的中文站是第三方，内容多为转述，价格带时间戳，新旧混排。
2. **看有没有 ctrl 面板入口**。官方页面会引导你进 ctrl 面板和客户区登录，第三方站给不出这个入口，只会把你往它的文章页带。
3. **看是否要你的账号密码**。任何要求你把 RackNerd 账号密码交给“代购”“代付”“代维”的，都不属于官方流程。下单、付款、开工单都应在 my.racknerd.com 内完成。

顺带说一句，第三方站之间也会互相矛盾。比如洛杉矶 DC02 机房是否已撤站，有站点称 2026 年 5 月已撤销、机器迁往 DC03，另一站点的促销文里却仍写“可选 DC02、DC03”。这条无法从官网核实，**下单页能选到哪些机房，就是当下真实可用的机房**。

## ctrl 面板：这家真正值得说的地方

很多介绍只提一句“有控制面板”，实际 ctrl 是 RackNerd 自研的 KVM VPS 面板，所有 VPS 在一个界面里管，功能密度不低：

- **电源与救援**：开机、关机、重启、power off，以及 rescue mode，破坏性操作前有确认。
- **HTML5 VNC 控制台**：带外访问，系统起不来或要装自定义系统时靠它。
- **系统重装、root 密码重置、改 hostname、网络重配置**：都不用开工单。
- **可选入站网络防火墙**：在面板里直接配规则。
- **用量仪表**：内存、磁盘、带宽三项在概览页可见，什么时候该升档一目了然。
- **一键安装应用**：AdminBolt、OpenClaw、Hermes Agent、AnythingLLM、Ollama、LibreChat、n8n 等，装完凭据直接显示在面板里。

底层仍然是 **unmanaged KVM**，一键安装只是可选的便利，你随时可以 SSH 上去用 Docker、Compose 搭自己的栈。官网还放了一个免账号的交互式 demo，防火墙和一键安装流程都能点着试，买之前想确认面板顺不顺手，可以先去点一遍。

对自托管用户来说，“装完凭据显示在面板内”这个细节省掉的是一轮排查：不用猜容器起没起来、密码在哪。

## 常见问题

**官网到底是 racknerd.com 还是 my.racknerd.com？**
racknerd.com 是官网和产品介绍页，my.racknerd.com 是客户区，注册、下单、付款、开工单、看账单都在这里。两个都是官方域名。

**面板地址换了没有？**
换了。旧面板是 nerdsvm.racknerd.com（SolusVM2），现在 VPS 管理在 ctrl 面板，官方帮助文档里的重装系统指引也是指向 ctrl。老用户按官方邮件通知的地址登录即可。

**能用支付宝吗？**
官方知识库只写明接受各大信用卡（AMEX、Discover、VISA 等）。支付宝支持只见于第三方说法，**以结账页实际显示的支付方式为准**。

**IP 被墙了怎么办？**
官方知识库有一条“Can I request IP replacement?”，写明 VPS 客户在特定期限内申请换 IP 可免费处理，超出期限则按付费换 IP 走。别自己来回重装系统，直接开工单或看知识库那条。

**年付能不能提前续费？**
第三方教程称可以在后台手动生成续费账单提前续。这条未经官方核实，操作前先开工单确认账单金额和生效方式，避免重复付款。

**有没有优惠码？**
没有任何可核验的官方优惠码可以给。官网的折扣体现在特价页和活动款上，结账时看到的价格就是实价，不用去第三方站找码。
